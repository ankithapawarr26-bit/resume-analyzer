# ✦ ResumeIQ

### Smart Resume Analyzer & ATS-Style Resume Improvement Platform

ResumeIQ is an interactive web application that analyzes resume content, detects skills, evaluates resume structure, compares keywords with a target job description, and provides actionable recommendations.

## 🚀 Features

- Resume text analysis
- TXT file upload
- Drag & drop upload
- ATS-style compatibility score
- Resume section detection
- Technical skill detection
- Job description comparison
- Keyword matching
- Missing keyword detection
- Strengths and weaknesses
- Personalized recommendations
- Resume improvement checklist
- Dark mode
- LocalStorage
- Analysis export
- Responsive design

## 📊 Analysis Categories

ResumeIQ evaluates:

- ATS Structure
- Skills
- Keywords
- Content
- Resume Sections
- Contact Information
- Action-oriented language

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- File API
- DOM Manipulation
- Responsive Web Design
